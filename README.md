ImageJ macros written to open a folder of micrograph files (format variable, can edit in code), detect the nucleus or nuclear envelope based on Hoescht/DAPI signal, and measure signal intensity in specific channels (antibodies/fluorescence, can edit specific channels in code).
Inputs ≥1 files in standard imaging formats (.tiff, .nd2, etc) in single folder.
Outputs csv files for each image with measurements of ROIs.
